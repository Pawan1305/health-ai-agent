# 🏥 MediMind AI — Healthcare Multi-AI Agent

A full-stack MERN application featuring a healthcare assistant that analyzes **multiple AI responses**, selects the most relevant natural guidance, and streams it in real-time with optional personalization using medical context.

---

## ✨ Features

- 🤖 **Multi-AI Response Analysis** — Analyzes multiple AI responses to deliver relevant guidance
- 🧠 **Natural Response Selection** — Chooses the most relevant raw reply instead of forcing a fixed template
- 🏥 **Medical Context** — Personalize responses with your health profile
- ⚡ **Streaming Responses** — Real-time token-by-token response like ChatGPT
- 💬 **Conversation History** — Persist chats in MongoDB
- 🛡️ **Prompt Leakage Protection** — Internal/system prompt text is sanitized from user-facing responses
- 🆘 **Graceful Fallback** — If engines fail, app returns local safety-oriented guidance instead of crashing
- 🌙 **Premium Dark UI** — Glassmorphism, animated gradients, Framer Motion
- 📱 **Responsive Design** — Works on mobile, tablet, and desktop
- 📋 **Markdown Rendering** — Formatted AI responses with code blocks, tables, lists

## 🚀 Quick Start

### Step 1 — Get API Keys

1. Get Gemini key from **[Google AI Studio](https://aistudio.google.com/app/apikey)** (optional)
2. Get OpenAI key from **[OpenAI Platform](https://platform.openai.com/api-keys)** (optional)
3. Add your AI keys in `.env` (e.g., `GEMINI_API_KEY`, `OPENAI_API_KEY`)
4. Start the backend and frontend

> Note: API usage costs and limits depend on your OpenAI and Google accounts.

---

### Step 2 — Clone & Setup Backend

```bash
cd backend
npm install
cp .env.example .env
# Edit .env and paste your GEMINI_API_KEY
# Add your AI keys in backend/.env
npm run dev
```

You can also run production mode:

```bash
npm run start
```

### Step 3 — Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### Step 4 — Open the App

Visit `http://localhost:5173` 🎉

## 🔧 Environment Variables

### `backend/.env`
```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/medimind
GEMINI_API_KEY=AIza...your_key_here
OPENAI_API_KEY=sk-...your_key_here
OPENAI_MODEL=gpt-4o-mini
GEMINI_MODEL=gemini-1.5-flash-latest
SHOW_ENGINE_DIAGNOSTICS=false
CLIENT_URLS=http://localhost:5173
ALLOW_VERCEL_PREVIEWS=true
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

Notes:
- Add your AI keys in `.env`.
- Responses are generated by analyzing multiple AI outputs and selecting the most relevant response.
- `SHOW_ENGINE_DIAGNOSTICS=false` keeps technical provider errors out of user-facing responses.

## 🚢 Deployment (Vercel + Render)

### Frontend (Vercel)

Set this environment variable in Vercel project settings:

```env
VITE_API_BASE_URL=https://<your-render-service>.onrender.com/api
```

Build settings:
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

### Backend (Render)

Create a Web Service from `backend/` with:
- Build command: `npm install`
- Start command: `npm run start`

Set environment variables in Render:

```env
NODE_ENV=production
PORT=10000
MONGODB_URI=<your_mongodb_connection_string>
OPENAI_API_KEY=<your_openai_key>
GEMINI_API_KEY=<your_gemini_key>
OPENAI_MODEL=gpt-4o-mini
GEMINI_MODEL=gemini-1.5-flash-latest
SHOW_ENGINE_DIAGNOSTICS=false
CLIENT_URLS=https://<your-vercel-app>.vercel.app
ALLOW_VERCEL_PREVIEWS=true
```

Notes:
- `VITE_API_BASE_URL` must include `/api` at the end.
- Add any custom frontend domains to `CLIENT_URLS` (comma-separated).
- Keep `ALLOW_VERCEL_PREVIEWS=true` if you want preview deployments to work without updating CORS each time.

## 💡 How It Works

1. **Add Medical Context** — Enter your age, conditions, medications, allergies
2. **Ask Questions** — Chat naturally about symptoms, medications, conditions
3. **AI Analysis** — Backend gathers multiple AI responses for the same user query
4. **Response Selection** — Backend sanitizes outputs and selects the most relevant natural response
5. **Large-Output Refinement** — If output is too long, backend asks a working engine to compress it naturally
6. **Fallback Mode** — If external AI services fail, backend returns local safety-oriented guidance
7. **Stream & Save** — Final response streams in real-time and is saved to MongoDB
